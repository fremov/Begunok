# Правила проекта

- Перед реализацией обсуждать с пользователем план, архитектуру, инструменты, риски и открытые вопросы. До согласования плана не менять код и окружение. После явного согласования выполнять работу по шагам: реализация → тестирование → установка на Android → обновление согласованного сайта на ПК → проверка совместимости, если эти шаги применимы. При существенном отклонении от плана сначала обсудить его с пользователем. Для MyLife Web на порту 8765 по-прежнему нужна отдельная прямая команда.
- MyLife Web (`http://127.0.0.1:8765/`, `D:/Dev/MyLifeWeb`) — отдельный проект. Не проверять, не запускать, не обновлять и не менять его без отдельной прямой команды пользователя. Обновление Android-приложения или сайта графиков не является такой командой.
- Для задач по импорту показателей использовать отдельный сайт «MyLife — графики» (`http://127.0.0.1:8786/`, `D:/Dev/MyLifeAnalytics`). При изменении импорта обновлять приложение на телефоне и этот сайт, проверять совместимость по USB. Передавать показатели с телефона на ПК только по USB, без туннелей, SSH, паролей, токенов и Sintence. Пользовательские данные сохранять.
- Если отдельная задача затрагивает обмен через Sintence, обновлять соответствующие настольную и серверную части Sintence.
