# Правила проекта

- После каждого обновления и установки MyLife на телефон также обновлять приложение на ПК, используемое для синхронизации данных MyLife (локальный MyLife Web в `D:/Dev/MyLifeWeb`). Не считать обновление завершённым, пока обе стороны не обновлены и совместимость синхронизации не проверена. Если изменения затрагивают обмен через Sintence, также обновлять соответствующие настольную и серверную части Sintence. Пользовательские данные сохранять.
