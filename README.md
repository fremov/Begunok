# MyLife

Android-приложение для бега, тренировок, привычек и здоровья (раньше называлось «Бегунок»). Бег — с нагрудным пульсометром (BLE Heart Rate Profile, проверено с Coospo H6) и GPS.

- Подключение к пульсометру с автопереподключением, заряд батареи, режим симуляции.
- Тренировка в foreground service: работает с выключенным экраном, уведомление с паузой и стопом.
- Дистанция, скорость, текущий и средний темп, фильтрация GPS.
- Граница пульса: звук, вибрация и голос, если пульс выше или ниже границы.
- Интервальные программы «бег/шаг» с голосовыми командами, свои программы.
- Беговой и силовой день: бег, перерыв и тренировка на площадке (турник и брусья) по кнопке. После завершения — обязательная трёхминутная заминка, затем сохранение тренировки. Таймеры отдыха, голосовые подсказки, отметка «получилось / не получилось» для каждого подхода.
- Пропуск разминки и упражнений прямо во время тренировки: пропущенное упражнение не меняет цель на следующий раз.
- Прогрессия: упражнения со ступенями от лёгкого к сложному, цели по повторам растут сами, программа бега предлагает следующий уровень после трёх успешных тренировок.
- Чтение: книги с прогрессом, страницы за день и неделю, дневная цель, серия дней и прогноз, когда дочитаете.
- Health Connect: шаги, пульс, SpO2, сон и активные калории с браслета (например, Xiaomi через Mi Fitness), шаги и каденс за тренировку.
- Вес: взвешивания с графиком и средним за неделю, цель по весу со сроком, прогресс, прогноз даты по тренду и нужный темп в неделю.
- Напоминания в настройках: взвешивание ежедневно в 07:15, короткая разминка по будням каждые 30 минут с 10:30 до 18:30, быстрые отметки состояния утром и вечером (по умолчанию 09:00 и 21:00, время меняется). Каждый тип можно отключить отдельно.
- Психологическое состояние: WHO-5, PSS-10, GAD-7 и PHQ-9 на русском, результаты и исходные ответы в локальной истории. После сохранения — одно напоминание о повторе через 14 дней (PSS-10 — через 30 дней); переключатель перенесён в настройки. Расписание восстанавливается после перезагрузки и обновления приложения, время доставки зависит от ограничений Android и разрешения на уведомления.
- Быстрая отметка состояния: настроение, напряжение и энергия от 0 до 10, необязательный контекст. Можно сохранять несколько отметок в день, каждая хранится со своим временем; история и удаление доступны в разделе психологического состояния.
- Замена упражнения прямо во время тренировки: другая ступень той же лесенки, только на сегодня.
- Аналитика с переключателем «Все / Бег / Силовой»: километры считаются только в беге, план недели — 3 беговых и 2 силовых.
- В аналитике есть отдельная вкладка «Психологическое состояние»: графики трёх быстрых оценок и каждой из четырёх шкал, выбор конкретной записи, средние по наблюдаемым дням, сравнение равных периодов и утра с вечером. Пропуски не считаются нулями, частые отметки в один день не увеличивают вес этого дня. Переключатель разделов отображает названия в одну строку; на узком экране он прокручивается горизонтально.
- Под показателями времени холодного душа и шагов — компактный цветной календарь активности без горизонтальной прокрутки. По умолчанию открыт текущий месяц; стрелки переключают месяцы, нажатие на заголовок открывает выбор месяца и года, переключатель «Месяц / Год» показывает календарный год. У тренировок, учёбы, чтения, LoL, душа и шагов свои цвета: несколько цветных полос в ячейке показывают все занятия дня. Показатели за месяц, год или выбранный день окрашены в те же цвета. LoL — одна активность для всех режимов, включая ARAM и ARAM «Хаос»: число игр и их суммарная длительность без двойного учёта. Для душа показана фактическая суммарная длительность, включая незавершённые сеансы, а не количество; график душа также показывает время. Нажатие на день показывает детали; повторное нажатие или крестик возвращает итоги периода. Календарь независим от фильтров тренировочной аналитики; отдельный блок активности из математики убран. Игры своего профиля берутся из доступной истории Riot, шаги — из доступных записей Health Connect. Демо-игры не учитываются, отсутствие данных обозначено «—», а не нулём.
- ARAM «Хаос» недоступен через Riot Match API. Его история дополняется собственными завершёнными играми из клиента League: настольный Sintence с включённым `SINTENCE_ACTIVITY=1` читает дату, очередь и длительность через LCU и сохраняет их в приватной истории сервера. MyLife получает её только после явной привязки своей установки к настольному Sintence (`POST /v1/activity/readers` с токеном телефона; токены не публикуются). Обычная история Riot и история клиента объединяются по ID матча без двойного учёта. Нужен запущенный Sintence рядом с клиентом League для поступления новых игр; уже переданные записи остаются на сервере. В календаре видны время последней синхронизации и ошибки отдельных источников; недоступный источник не стирает успешно прочитанные игры другого.
- Шаги не хранятся как собственный счётчик MyLife: приложение читает дневные суммы Health Connect. В разделе «Здоровье» нужно разрешить чтение шагов, а для полной доступной истории — дополнительное чтение истории (если устройство его поддерживает). Без него Android по умолчанию открывает данные только начиная с 30 дней до первого предоставления разрешений, а не всю историю: [ограничение Health Connect](https://developer.android.com/health-and-fitness/health-connect/read-data#read-data-older-than-30-days). Ошибки чтения и ограничения истории показываются отдельно от отсутствующих данных.
- Финансы: импорт CSV-выписок Т-Банка с предварительным просмотром и защитой от повторной загрузки, ручные доходы и расходы, история операций и правила включения/исключения переводов.
- Тема оформления: системная, светлая или тёмная (в настройках).
- League of Legends: поиск игроков с подсказками ников, свой профиль, избранные со статусом «в игре», профиль с рангами, мастери, последними играми и составами текущей игры. Данные идут через сервер Sintence; адрес сервера и свой Riot ID задаются в `local.properties` (`lol.server`, `lol.me`), в git они не попадают.
- Все разделы собраны в боковом меню, сгруппированы по тренировкам, привычкам и здоровью.
- Холодный душ: таймер с голосовыми подсказками, цель растёт с 1 до 3 минут на 15 секунд после трёх успешных душей подряд, минуты холода за неделю и серия дней.
- Аналитика в истории: периоды, неделя к неделе, рекорды, интерактивные графики дистанции, темпа и пульса, графики по каждому упражнению.
- Дизайн на Material 3 Expressive: своя тёмная тема, шрифт Roboto Condensed для цифр, анимации пульса и таймеров, переходы между экранами, заставка с логотипом.
- Свой голос для команд: выбор синтеза речи, свои аудиофайлы или голосовой пакет, переозвученный через RVC.
- История: маршрут, раскрашенный по пульсу, график пульса, экспорт в GPX (с пульсом, для Strava и Garmin).

Шрифт Roboto Condensed распространяется по лицензии SIL Open Font License, текст лицензии в [licenses/RobotoCondensed-OFL.txt](licenses/RobotoCondensed-OFL.txt).

### Финансы

В боковом меню откройте **Финансы → Импорт CSV** и выберите выгрузку операций Т-Банка размером до 20 МиБ. Поддерживается CSV с русскими заголовками, разделителем `;`, десятичной запятой, UTF-8 или Windows-1251. OFX не требуется: CSV дополнительно содержит категории и банковский признак «Учёт в аналитике». Файл читается локально, без отправки на сервер; перед сохранением показывается предварительный просмотр.

Для расчётов берётся **сумма в валюте счёта**, без добавления округления и бонусов. Ошибочные операции видны в истории, но не считаются доходом или расходом. Валюты анализируются отдельно: автоматической конвертации нет. Разница доходов и расходов — денежный поток за выбранный период, а не остаток на банковском счёте.

По умолчанию учитывается банковский признак «Учёт в аналитике». На вкладке **Правила** можно исключать или включать операции по направлению, счёту, категории, части описания, валюте и диапазону сумм. Заполненные условия действуют совместно; новые правила имеют приоритет перед старыми. Правила применяются и к уже загруженной истории. Для отдельной операции доступны «Авто», «Учитывать», «Исключить»; индивидуальное решение важнее правила. Неуспешную операцию нельзя включить в расчёты. Исключение ничего не удаляет.

Кнопки **Доход** и **Расход** позволяют внести подработку или другую операцию вручную с датой, суммой, валютой, счётом, категорией и заметкой. Ручные записи можно изменять и удалять; для банковских записей доступны изменение категории и режима учёта.

Аналитика включает доходы, расходы, разницу, долю сохранённого дохода, средний расход в день, сравнение с предыдущим периодом той же длины, динамику по дням/неделям/месяцам, категории, счета, получателей расходов и крупнейшие операции. Фильтры периода, валюты, счёта, категории и поиска действуют на расчёты. «Месяц» и «Год» заканчиваются сегодняшним днём, чтобы будущие дни не занижали средние. Дополнительные фильтры раскрываются отдельно; длинные графики листаются по 30 точек.

Повторный импорт и пересекающиеся выгрузки не создают повторные записи. Статус и банковский признак учёта существующей операции обновляются из новой выписки; изменённая в приложении категория и индивидуальный режим учёта сохраняются. В CSV нет уникального банковского идентификатора: сопоставление использует исходные реквизиты операции и порядковый номер среди полностью одинаковых строк. Несколько одинаковых операций внутри одной выписки сохраняются раздельно; изменения исходных реквизитов между выгрузками могут потребовать ручного исключения лишней записи.

### Математика с нуля

Начиная с **0.7**, раздел **Математика** содержит полный офлайн-курс Spacemath: все 75 уроков, теорию, примеры, задачи, изображения и 914 раскрываемых решений. Материалы входят в APK, доступны сразу и не требуют интернета или предварительного открытия сайта. Есть поиск, фильтры прохождения и продолжение последнего урока. Переходы между темами остаются внутри приложения, внешних ссылок на сайт в просмотрщике нет; поддерживаются светлая и тёмная темы.

Тема завершается только по собственной отметке; её можно снять. Решённые задачи отмечаются вручную по одной, без автоматической проверки ответа. Открытие страницы или решения не создаёт учебную активность. Первые прохождения тем, задачи и повторения отображаются в общем календаре активности в аналитике; история не стирается при снятии отметки прохождения.

Интервальное повторение — адаптация [SM-2](https://www.super-memory.com/english/ol/sm2.htm) к темам: сначала вспомните правило и решите задачу без подсказки, потом выберите «Не вспомнил / Трудно / Вспомнил / Легко». После первого прохождения повторение назначается на завтра; успешные интервалы далее — 6 дней, затем прежний интервал × коэффициент лёгкости с округлением вверх. Неудача возвращает интервал к одному дню; материал стоит разобрать сразу. Коэффициент начинается с 2,5, не опускается ниже 1,3 и зависит от самооценки. Расписание одной темы продвигается не чаще раза в день и только при наступлении срока. Повторение помогает практике, но не гарантирует запоминание.

Отдельный DataStore `math.preferences_pb` хранит прохождение, расписания и независимые события действий. Он переносится между телефоном и сайтом через существующую USB-синхронизацию без изменения Room-схемы; независимые задачи одного дня объединяются, конфликтующие изменения одного расписания требуют выбора.

Учебные тексты сохранены без изменения, реклама и внешние виджеты удалены. Пакет `app/src/main/assets/math` занимает около 23,5 МБ и совпадает с пакетом сайта. Материалы включены для личного приложения после подтверждения пользователем разрешения на полное копирование; это не открытая лицензия на перепубликацию. Импортёр `tools/import_spacemath.py` (dev-зависимость `beautifulsoup4==4.15.0`) обновляет оба пакета командой `python tools/import_spacemath.py --web-root D:/Dev/MyLifeWeb`; исходные загрузки кэшируются вне репозитория. Утраченная на источнике схема восстановлена из архивного оригинала, URL записан в импортёре.



### Локальный сайт и перенос по USB

Личный сайт [MyLife Web](https://github.com/fremov/MyLifeWeb) находится в отдельном приватном репозитории: React, Vite и Tailwind CSS. Он работает на компьютере через `127.0.0.1`; личная база и резервные копии не публикуются в Git.

Начиная с debug-версии **0.5**, сайт переносит по USB все собственные записи приложения, настройки и внутренние пользовательские файлы в обе стороны. Используется трёхстороннее слияние с явным выбором конфликтов, резервной копией до записи и проверкой результата. Активная тренировка блокирует перенос. Нужны USB-отладка и разрешение подключения на телефоне.

Debug-мост `.sync.DesktopExportActivity` защищён системным разрешением `android.permission.DUMP` (shell/system); в release-сборку он не входит. Он сохраняет датированный снимок доступных показателей Health Connect за 30 дней для чтения на сайте. Сама история MyLife переносится полностью; Health Connect не перезаписывается. Внешние файлы по `content://` остаются ссылками и отмечаются предупреждением, внутренние голосовые пакеты копируются.

### Психологические опросники

Формулировки: [WHO-5 — ВОЗ](https://cdn.who.int/media/docs/default-source/mental-health/who-5_russian.pdf), [PSS-10 — Абабков и соавт., 2016](https://psyjournals.ru/journals/vspu_psychology/archive/2016_n2/vspu_psychology_2016_n2_Ababkov_et_al.pdf), [GAD-7](https://www.phqscreeners.com/images/sites/g/files/g10060481/f/201412/GAD7_Russian%20for%20Russia.pdf), [PHQ-9](https://ifightdepression.com/media/193/download/PHQ-9.pdf?v=1).

WHO-5: 0–100 баллов, больше — лучшее самочувствие. PSS-10 использует оригинальное кодирование 0–4 и сумму 0–40 с обратными пунктами 4, 5, 7, 8, а не диапазон 10–50 из русской адаптации; диагностические пороги не применяются. GAD-7: 0–21; PHQ-9: 0–27. Положительный ответ на девятый пункт PHQ-9 показывает информацию об экстренной поддержке независимо от суммы.

Перед распространением приложения нужно проверить условия использования опросников и переводов: WHO публикует материал по CC-BY-NC-SA, для PSS запросы на использование направляются через MAPI/ePROVIDE. Приложение предназначено для личного самонаблюдения.

## Установка

Скачайте `begunok-vX.Y.Z.apk` из [Releases](../../releases) и откройте его на телефоне. Нужен Android 8.0 или новее.

## Сборка

Откройте проект в Android Studio и нажмите Run, либо выполните:

```
./gradlew assembleDebug
```

APK будет в `app/build/outputs/apk/debug/`.

## Релизы

Новый релиз собирается GitHub Actions при пуше тега:

```
git tag v1.0.0
git push origin v1.0.0
```

Для подписи нужны секреты репозитория `RELEASE_KEYSTORE_BASE64`, `RELEASE_STORE_PASSWORD`, `RELEASE_KEY_ALIAS` и `RELEASE_KEY_PASSWORD`.
